# Figma 交付
Figma：https://www.figma.com/design/vHq5a7gAf59V1lDiR94NdH
每次选择一个完整 Frame，复制链接，通过 Figma MCP 读取设计上下文。先提取 Design Tokens，再做公共组件，然后逐页实现。小程序使用原生组件/TDesign，后台使用 React/Ant Design。每页截图与 Figma 对照。不要一次性自动转码整份 Figma；流程、字段、权限有冲突时先更新文档并确认。
