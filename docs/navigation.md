## 第三阶段 2.4 路由验收范围

| 客户端 | 一级入口 | 二级页面与返回 |
|---|---|---|
| 会员小程序 | 首页、积分、商城、订单、个人中心 | 商城 → 商品详情 → 兑换确认 → 兑换成功 → 订单详情或订单列表。订单详情返回订单列表。个人中心 → 会员资料 → 个人中心。 |
| 员工小程序 | 工作台、客户列表、回访任务、员工资料 | 客户列表 → 客户详情 → 跟进记录、家访记录或跟进历史。返回客户详情时保留客户 ID。 |
| 管理后台 | 上表中的 12 个一级菜单 | 会员和员工管理各进入详情，客户跟进进入回访提醒，积分管理进入流水，商品管理进入新增、详情、编辑和库存调整，兑换订单进入订单详情，核销记录进入凭证核销。 |

小程序从 `/pages/index/index` 进入演示身份选择页 `/pages/auth/index`。切换身份会清空旧页面栈，打开新身份的首页或工作台。详情页优先按原页面栈返回，直接打开详情时可返回所属列表。商城、订单和客户链接传递演示 ID。

后台支持二级页面直链。登录后回到请求的地址，保留查询参数和锚点。部署时需将前端页面请求回退到 `index.html`，由前端路由显示页面或 404。

## 交互状态验收清单

| 场景 | 状态与行为 |
|---|---|
| 登录与守卫 | 初始校验、未登录、会话过期、角色无权限、资源不可见。会话失效回登录，业务写入失败保留表单，待开放功能不给出可提交入口。 |
| 列表与详情 | 初次加载、刷新、加载更多、空列表、筛选无结果、错误重试、不可见、下架。详情返回列表保持筛选与页码。 |
| 表单 | 初始、编辑、校验中、字段错误、提交中、成功、业务拒绝、网络异常。禁用重复点击；网络结果未知时使用原幂等键和原请求重试，用户修改请求后生成新键。 |
| 月限兑与商城 | 缺货、积分不足、额度不足、商品下架、成功。额度提示使用服务端返回值，订单状态和成本以服务端结果为准。 |
| 待核销与凭证 | 待核销、凭证加载、有效、过期、重新签发、已核销。刷新后只展示新凭证，离页清除本地明文。核销成功更新详情；重复、无效、过期及越权显示各自结果。 |
| 客户跟进与转移 | 当前归属、转移中、归属已变、完成、无权限。提交冲突时刷新负责人和候选，仍须填写转移原因。 |
| 任务 | 待处理、延期、完成、忽略。员工手动联系，界面呈现时间及状态。 |
| 后台管理 | 读写权限分别控制，展示数据脱敏；商品版本冲突时刷新对比，库存和积分调整成功后刷新快照及流水。 |
