# 开发阶段与验收清单

## 阶段 A：工程准备
- [ ] 检查现有仓库、分支、README、运行方式
- [ ] 确认前端/后端技术栈与版本
- [ ] 确认部署环境、数据库、缓存、文件存储
- [ ] 配置环境变量模板，不提交密钥
- [ ] 建立 lint、format、typecheck、test、build 命令
- [ ] 建立开发/测试环境和演示账号方案

## 阶段 B：前端 UI
- [ ] 会员端移动端布局
- [ ] 员工端移动端布局
- [ ] 管理后台桌面端布局
- [ ] 公共组件与设计 Token
- [ ] 路由、导航与权限守卫
- [ ] 表单校验、加载/空/错误/无权限状态
- [ ] 不出现预约挂号/预约管理
- [ ] 不出现临床档案/临床数据录入和存储

## 阶段 C：业务逻辑
- [ ] 会员注册和账号关联
- [ ] 员工客户归属、转移与历史
- [ ] 运营跟进任务与联系记录
- [ ] 积分账户和积分流水
- [ ] 商品管理、库存与兑换
- [ ] 订单状态与核销
- [ ] 权限校验和操作日志

## 阶段 D：关键测试
- [ ] 未登录用户不能访问受保护页面/API
- [ ] 不同角色只能访问授权功能
- [ ] 会员不能查看他人积分和订单
- [ ] 积分余额与流水一致
- [ ] 重复提交兑换不会重复扣积分/扣库存
- [ ] 并发兑换和库存不足有明确处理
- [ ] 核销凭证过期、重复使用、伪造时拒绝
- [ ] 客户转移有权限控制和操作留痕
- [ ] 运营回访字段不包含临床数据
- [ ] 搜索、分页、筛选、导出遵循权限与脱敏规则

## 阶段 E：上线准备
- [ ] 业务方确认积分规则
- [x] 业务方确认商品自然月限兑口径及业务时区
- [ ] 业务方确认库存写权限和运营细则
- [ ] 业务方确认核销流程及员工权限
- [ ] 完成隐私政策、用户授权及数据处理审查
- [ ] 完成备份恢复演练
- [ ] 完成 UAT 签字与回滚方案
