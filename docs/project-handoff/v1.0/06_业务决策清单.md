# 开发前需要业务方确认的决策

| 项目 | 当前状态 | 需要确认的内容 |
|---|---|---|
| 技术栈 | 已确认 | 见[技术栈](../../tech-stack.md) |
| 会员注册 | 有页面设计 | 注册字段、手机号验证、微信授权/登录方式 |
| 注册赠分 | 暂未启用/待确认 | 是否赠送、赠送数量、生效时间 |
| 积分获取 | 未完整定义 | 消费/活动/员工录入等来源及计算规则 |
| 积分有效期 | 未定义 | 是否过期、过期提醒、过期扣减 |
| 积分调整 | 未定义 | 人工补分/扣分权限、原因和审批 |
| 商品限兑 | 已确认 | 每会员、商品、自然月累计数量，时区 `BUSINESS_TIMEZONE=Asia/Shanghai`，订单 `created_at` 确定归属。运营需确认降额后的展示 |
| 商品库存 | 事务扣减及流水设计已形成 | 运营调整和店长写权限 |
| 兑换撤销 | 已确认排除 | V1.0 不支持订单取消或退款 |
| 核销方式 | 设计稿有二维码示意 | 动态凭证有效期、一次性规则、核销角色 |
| 员工客户归属 | 有客户转移功能 | 自动分配规则、转移审批、离职交接 |
| 回访提醒 | 有回访周期设置 | 周期、触发条件、通知渠道 |
| 角色权限 | 有权限页面 | 管理员、店长、员工的具体权限矩阵 |
| 隐私与保留 | 未定义 | 数据最小化、脱敏、保留/删除、导出权限 |

## 不能由开发人员自行决定
仍需业务负责人的决策见[现行待确认事项](../../open-questions.md)。已确认规则见[业务规则](../../business-rules.md)。
