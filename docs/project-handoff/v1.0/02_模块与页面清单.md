# 模块与页面清单（开发拆分参考）

2. 会员首页

5. 兑换确认

9. 我的兑换/兑换订单
10. 个人资料

## 页面实现原则
- 页面先按 Figma 的布局、色彩、字号、间距实现。
- 公共导航、卡片、标签、表格、筛选栏、弹窗、表单应抽成可复用组件。
- 空状态、加载态、失败态、无权限态、表单校验态必须设计。
- 预约相关页面和路由不得出现。
- 不得出现临床病历字段或临床数据详情页。
