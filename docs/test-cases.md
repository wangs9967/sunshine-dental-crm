# 测试验收基线
- 微信身份服务端换取；重复注册拒绝；手机号默认脱敏。
- scene_token 过期/撤销拒绝；已有客户扫码不改绑；客户转移保留历史。
- 到店、消费、成交独立；员工只访问本人当前负责客户。
- 家访、到店回访、电话、微信跟进可保存；有效联系更新时间。
- 提醒任务生成去重，员工手动联系。
- 积分变更写不可变流水，余额不为负，幂等请求不重复入账。
- 兑换检查商品、库存、积分、限兑；并发不超卖；事务失败整体回滚。
- 相同幂等键不创建重复订单；重复核销拒绝；越权拒绝。
- manager 管理本门诊全部业务；数据库无 stores/store_id；API 无门店切换。
- 审计日志不含明文手机号、密码或密钥。
