# V1.0 待确认事项

以下待定项不会改变已冻结业务规则。相关权限及写入口在评审前关闭，已经明确的读取范围按[权限矩阵](permissions.md)设计。

| 项目 | 需确认的决策 |
|---|---|
| 会员资料 | 是否验证手机号、家庭共用手机号、允许修改的字段及验证流程 |
| 员工账号 | 开通与绑定方式、员工小程序登录和身份切换、是否提供后台代录客户 |
| 归属交接 | 离职客户处理和是否需要额外审批 |
| 积分发放 | 积分来源、计算、有效期及人工调整审核与额度。V1.0 注册赠分当前关闭 |
| 商品和库存 | 上架或兑换时间窗、月上限下调后的展示与处理、店长的商品及库存写权限 |
| 核销与领取 | 动态凭证时长和刷新规则、逾期订单的运营处理、普通员工核销权限 |
| 回访 | 唤醒阈值、生成时间、去重窗口与延期策略 |
| 后台授权 | 店长的员工管理、积分调整、系统设置及审计权限。手机号明文、导出与保留策略 |
| 页面视觉基线 | 可访问的 Figma 版本与逐页冻结确认 |

已确认 BUSINESS_TIMEZONE=Asia/Shanghai，以订单 created_at 判定自然月。V1.0 的兑换订单无取消及退款流程。详见[业务规则](business-rules.md)。
