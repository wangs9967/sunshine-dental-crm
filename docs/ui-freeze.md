## 1. Freeze 规则

V1.0 开发以当前 Figma 为唯一视觉基线。Freeze 后允许的变更仅包括：

1. 明确的 UI 缺陷修复；
2. 文案修正；
3. 不改变业务流程的轻微间距/适配调整；
4. 已评审批准的需求变更。

任何新增页面、业务流程变化、字段变化或权限变化，必须先更新产品/技术文档，再修改 Figma 与代码。

## 4. 开发实现约束

- 前端不得自行创造新的主视觉体系；
- 复用统一按钮、卡片、标签、状态色、表单和导航样式；
- 权限导致的不可见/不可用状态必须由后端权限再次校验；
- 移动端实现时允许按微信小程序安全区域做响应式适配；
- 管理后台允许为不同屏幕宽度做响应式处理，但信息层级不得改变。
