# 角色与权限（单门店）
角色：member、employee、manager、admin。manager 管理阳光口腔全部业务，不存在门店级隔离。

| 功能 | member | employee | manager | admin |
|---|---|---|---|---|
| 本人资料/积分/订单 | 本人 | - | 管理查询 | 管理查询 |
| 客户与跟进 | - | 本人当前负责客户 | 全部 | 全部 |
| 员工二维码 | - | 本人二维码 | 全体 | 全体 |
| 员工管理 | - | - | 按授权 | 是 |
| 客户转移 | - | - | 是 | 是 |
| 提醒任务 | - | 本人任务 | 全部 | 全部 |
| 商品管理 | - | - | 待确认 | 是 |
| 订单核销 | - | 待确认 | 是 | 是 |
| 积分调整 | - | - | 待确认 | 是 |
| 系统配置/审计 | - | - | 待确认 | 是 |

所有权限由后端验证。employee 仅访问本人当前负责客户；客户转移仅 manager/admin；手机号默认脱敏；敏感操作审计。未确认权限拒绝优先。
