# V1.0 业务规则
## 已确认
- 单门店，仅服务阳光口腔；会员/员工共用一个微信原生小程序，管理后台独立 Web。
- 不接支付，不存储临床病历、诊断、影像、治疗方案。
- 会员微信登录后填写姓名、生日、手机号；微信身份由后端临时 code 换取，不信任客户端自报 openid。
- 员工专属二维码由服务端签发 scene_token。新会员首次扫码绑定来源员工；已有负责人的会员再次扫码不得自动改绑。
- 首次来源员工永久保留；当前负责人通过归属历史维护。客户转移仅店长/管理员，记录前后负责人、操作人、时间、原因。
- 到店 not_visited/visited、消费 not_consumed/consumed、成交 not_dealt/dealt 三项独立。
- 跟进类型 phone、wechat、home_visit、store_visit、other；家访与到店回访统一记录。
- 系统生成复查/唤醒名单，员工手动联系；不自动发送营销消息。
- 积分变动必须有不可变流水；兑换扣积分、写流水、扣库存、创建订单和核销码必须同一事务并支持幂等。
- 不创建 stores 表，不在业务表增加 store_id，不做门店切换/跨门店隔离。

## 待确认
积分奖励与获取渠道、积分有效期、调整审批、商品领取期限、取消退款规则、员工登录方式、短信验证、沉睡阈值、提醒频率、员工核销范围、会员资料修改规则，见 open-questions.md。
